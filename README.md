# RentCar Bogotá

## Descripción del proyecto

RentCar Bogotá es una empresa ficticia dedicada al alquiler de vehículos en Bogotá, Colombia. Actualmente, la gestión de reservas, la disponibilidad de vehículos, los clientes y los pagos se realiza en gran parte mediante procesos manuales.

El proyecto propone desarrollar un sistema web de gestión y reservas que centralice esta información y facilite las operaciones de la empresa.

## Problema

La gestión manual puede ocasionar errores, demoras, reservas duplicadas y dificultades para consultar la información de vehículos, clientes y alquileres. El sistema busca organizar estos procesos y ofrecer información actualizada para apoyar tanto a los clientes como al personal de la empresa.

## Objetivo

Desarrollar un sistema web que permita administrar vehículos, clientes y usuarios; consultar la disponibilidad de vehículos; gestionar reservas y sus fechas de alquiler y devolución; registrar métodos de pago; y generar reportes básicos.

## Usuarios del sistema

- **Cliente:** consulta vehículos disponibles y realiza reservas.
- **Empleado:** gestiona clientes, reservas y vehículos.
- **Administrador:** administra usuarios, vehículos, reservas y reportes.

## Alcance inicial

El sistema incluirá las siguientes funcionalidades:

- Registro y administración de vehículos.
- Registro de clientes.
- Consulta de disponibilidad de vehículos.
- Creación y gestión de reservas.
- Gestión de fechas de alquiler y devolución.
- Registro de métodos de pago.
- Gestión de usuarios.
- Generación de reportes básicos.
- Consultas de administrador.
