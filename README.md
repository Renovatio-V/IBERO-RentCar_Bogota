# RENTCAR Bogotá

Prototipo web de una experiencia de alquiler de vehículos en Bogotá. Incluye páginas para explorar carros, consultar viajes, ver una billetera y revisar un perfil.

## Sitio publicado

[Visitar RENTCAR Bogotá en GitHub Pages](https://renovatio-v.github.io/IBERO-RentCar_Bogota/)

## Funcionalidades

- Inicio con vehículos recomendados y formulario de búsqueda.
- Catálogo con filtros por tipo, marca y color.
- Modal de reserva de demostración con fechas, opciones de entrega y cálculo estimado.
- Páginas de inicio de sesión, viajes, billetera y perfil.
- Diseño adaptable a distintos tamaños de pantalla.

Este proyecto es un prototipo de interfaz: las reservas, el inicio de sesión y los datos mostrados son demostrativos; no se conectan a un servicio de autenticación ni procesan pagos reales.

## Cómo verlo localmente

Clona el repositorio y abre `index.html` en un navegador para ver el inicio de sesión. 

## Tecnologías

- HTML
- CSS
- JavaScript (sin frameworks ni dependencias de instalación)
